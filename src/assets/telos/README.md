Telos retains ownership of its marks. At the user's request, the login buttons render their alpha silhouettes with the portal's amber accent using CSS masks, preserving proportions and transparent letter cutouts. This custom color treatment differs from the brand guide's instruction to retain the supplied colors. The source images remain unchanged and are bundled locally.
